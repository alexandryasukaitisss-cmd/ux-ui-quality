# UX/UI Quality

[English](README.md) · [Навык](skills/ux-ui-quality/SKILL.md) · [Лицензия](LICENSE)

Навык Codex для работы с интерфейсом соразмерно задаче. Если непонятна одна кнопка, проверьте её состояния. Если меняется способ выполнить всю работу, проверьте путь целиком. Навык помогает провести эту границу в сайтах, веб-приложениях и нативных приложениях.

- **Начинайте с задачи человека.** Проверьте, что ему нужно увидеть, сделать и подтвердить, как он исправит ошибку.
- **Выбирайте глубину по изменению.** Для кнопки достаточно локальной проверки. Новый или рискованный процесс требует больше свидетельств.
- **Проверьте результат в приложении.** Для существенных визуальных изменений пройдите затронутые сценарии в интерфейсе. Укажите, что проверить не удалось.

## Как попробовать

В Codex CLI с поддержкой каталогов плагинов:

~~~sh
codex plugin marketplace add alexandryasukaitisss-cmd/ux-ui-quality
codex plugin add ux-ui-quality@ux-ui-quality
codex plugin list --marketplace ux-ui-quality
~~~

Затем попросите: **«Используй $ux-ui-quality. Объясни, почему кнопка отправки недоступна, и проверь затронутые состояния».** Codex может выбрать навык и сам, если его описание подходит к задаче.

В пакете только навык и справочные файлы. У него нет сервиса, MCP-сервера и сценария при установке. Поле аутентификации относится к формату каталога; собственный вход плагину не нужен.
